Projeto Ransomware Educacional em Python

## Arquivos
- `encrypter.py`: criptografa arquivos usando uma chave gerada.
- `decrypter.py`: descriptografa arquivos previamente criptografados.

## Tecnologias
- Python 3
- Biblioteca `cryptography`

## Objetivo
Demonstrar o funcionamento de um ransomware de forma ética e educacional, reforçando a importância da segurança de dados.

## Aviso Ético
Este projeto é **exclusivamente educacional**.  
O uso indevido de técnicas de criptografia para fins maliciosos é **ilegal**.
